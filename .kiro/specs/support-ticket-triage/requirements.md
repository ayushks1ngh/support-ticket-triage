# Support Ticket Triage Requirements

## User stories
- As support operations, I can submit one or many valid tickets and receive validated category, urgency, confidence, team, review status, and reason.
- As an operator, I can switch Groq/NVIDIA configuration without code changes.
- As a reviewer, I can run samples, tests, and evaluation without credentials.

## Acceptance
See `docs/REQUIREMENTS.md` for REQ-001 through REQ-016 and their test mapping. MVP is complete only when every row is `verified`, all offline quality gates pass, and live behavior remains optional.
